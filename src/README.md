# Código fuente

El código Java se organizará dentro de `src/main/java`.

Los ejemplos de cada patrón deben mantenerse separados para evitar conflictos:

```text
src/main/java/ar/edu/pizzeria/
├── modelo/
├── singleton/
├── observer/
└── strategy/
```

Por ahora solo se preparó la estructura. Las implementaciones de los patrones serán desarrolladas por el equipo.
